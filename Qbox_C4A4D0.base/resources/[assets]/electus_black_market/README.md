# electus_black_market

## Install

1. Import `electus_black_market.sql`.
2. Put this folder in your resources.
3. Ensure `oxmysql` before this resource.
4. Ensure `electus_gangs` before this resource if using zone shops.
5. Add `ensure electus_black_market` after dependencies.
6. Use `/manage_black_market` to manage black markets
